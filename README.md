# Gestión de incidentes simulados — FacturaPro

## Objetivo
Aplicar herramientas de gestión de incidentes para registrar,
clasificar, priorizar y dar seguimiento a eventos que afectan
la continuidad de un servicio o sistema.

## Contexto
FacturaPro es un sistema ficticio de facturación utilizado por
una organización. Esta práctica representa el trabajo del
equipo de soporte técnico.

## Casos de la práctica
1. Prioridad crítica: indisponibilidad total del sistema.
2. Prioridad media: error intermitente al descargar facturas en PDF.
3. Prioridad baja: solicitud de mejora del texto de un botón.
